# 对象提取标注规范

本规范用于构建“对象提取”训练数据。当前任务的目标不是识别句子里出现了哪些名字，而是识别哪些人是这句话里的执行对象。

## 1. 任务定义

给定一句课堂指令，从固定人名表中找出本句的执行对象。

当前固定人名为：

- `李昌龙`
- `崔展豪`
- `包梓群`
- `丽娃`
- `萧华诗`
- `张晓丹`

输出要求：

- 最多输出 3 个人名
- 可以输出 0 个
- 输出的是“执行动作的人”，不是“被帮助的人”或“被提及的人”

例如：

- `张晓丹你和丽娃讨论一下`
  标注结果：`张晓丹`、`丽娃`
- `张晓丹同学你帮丽娃解决一下这个问题`
  标注结果：`张晓丹`

## 2. 标注单位

训练数据采用二分类格式，每条样本由三列组成：

- `text`：原句
- `name`：候选名字
- `label`：该名字是否为执行对象

其中：

- `label=1`：该名字是执行对象
- `label=0`：该名字不是执行对象

示例：

```csv
text,name,label
张晓丹你和丽娃讨论一下这个问题,张晓丹,1
张晓丹你和丽娃讨论一下这个问题,丽娃,1
张晓丹你和丽娃讨论一下这个问题,崔展豪,0
张晓丹同学你帮丽娃解决一下这个问题,张晓丹,1
张晓丹同学你帮丽娃解决一下这个问题,丽娃,0
```

## 3. 核心判断标准

只看一个标准：这个名字对应的人，是否被老师要求在本句里执行动作。

如果是，标 `1`。如果不是，标 `0`。

优先考虑以下角色：

- 被点名去回答、提问、讨论、操作的人
- 被直接称呼并承担动作的人
- 与其他人一起共同完成任务的人

不要把以下角色标成执行对象：

- 被帮助的人
- 被讨论的人
- 被提醒、被通知、被解释的人
- 仅仅被举例、被提及的人

## 4. 明确标 `1` 的情况

### 4.1 直接点名执行

句式特征：

- `请A回答`
- `A你来回答`
- `A同学你说一下`
- `A你来提问`

示例：

- `请崔展豪回答这个问题`
  `崔展豪=1`
- `萧华诗你来提一个问题`
  `萧华诗=1`

### 4.2 多人共同执行

句式特征：

- `A和B讨论`
- `A跟B交流`
- `A、B、C一起讨论`
- `A、B和C商量一下`

示例：

- `张晓丹你和丽娃讨论一下`
  `张晓丹=1`
  `丽娃=1`
- `包梓群、李昌龙和崔展豪一起交流`
  `包梓群=1`
  `李昌龙=1`
  `崔展豪=1`

### 4.3 句首称呼 + 后续动作

如果句子先点名一个学生，再要求其做动作，通常该学生为执行对象。

示例：

- `张晓丹同学，你来回答一下`
  `张晓丹=1`
- `李昌龙，你继续说`
  `李昌龙=1`

## 5. 明确标 `0` 的情况

### 5.1 被帮助的人

句式特征：

- `A帮B...`
- `A帮助B...`
- `A协助B...`

默认规则：

- `A=1`
- `B=0`

示例：

- `张晓丹同学你帮丽娃解决一下这个问题`
  `张晓丹=1`
  `丽娃=0`

### 5.2 被通知、被提醒、被解释的人

句式特征：

- `A告诉B...`
- `A提醒B...`
- `A给B讲一下...`

默认规则：

- `A=1`
- `B=0`

示例：

- `崔展豪你给丽娃讲一下这道题`
  `崔展豪=1`
  `丽娃=0`

### 5.3 仅被提及，不承担动作

示例：

- `张晓丹的问题刚才谁回答得很好`
  如果句子没有要求张晓丹做事，则 `张晓丹=0`
- `你们参考一下丽娃刚才的做法`
  `丽娃=0`

## 6. 标注流程

每拿到一句原句，按下面步骤处理：

1. 先从固定人名表里找出本句出现过的名字
2. 对每个出现的名字单独判断是否为执行对象
3. 每个“原句 + 名字”生成一条样本
4. 给出 `label=1` 或 `label=0`

建议至少为每句补足：

- 所有实际出现的人名
- 1 到 2 个未出现或出现但非目标的人名负样本

这样负样本会更稳定。

## 7. 推荐标注范围

一条原句优先覆盖以下候选：

- 句中出现且可能是执行者的人名
- 句中出现但明显不是执行者的人名
- 少量其他固定人名作为负样本

不要无节制地为一句话生成所有 6 个名字，否则会让数据分布过度偏向负样本。

推荐经验：

- 1 个正样本时，配 1 到 3 个负样本
- 2 个正样本时，配 1 到 2 个负样本
- 3 个正样本时，配 1 到 2 个负样本

## 8. 易错规则

### 8.1 “和/跟/与” 不一定都是目标

一般在 `讨论/交流/商量` 这类动作里，连接两边的人通常都标 `1`。

但如果句子是：

- `A帮B和C解释一下`

通常执行者还是 `A`，`B`、`C` 不一定是执行者。要根据动作关系判断，不要只看连接词。

### 8.2 “你” 指向前面的被点名者

例如：

- `张晓丹你来回答`

虽然句子里有 `你`，但执行对象是前面的 `张晓丹`。

### 8.3 “同学” 不改变执行者身份

例如：

- `张晓丹同学你帮丽娃解决一下`

`同学` 只是称呼补充，不影响执行对象判断，仍是 `张晓丹=1`。

### 8.4 句子里出现多个名字，不代表都标 `1`

例如：

- `张晓丹你帮丽娃解决一下`
  `张晓丹=1`
  `丽娃=0`

### 8.5 没有明确执行者时可以全是 `0`

例如：

- `刚才张晓丹和丽娃讨论得不错`

这是陈述句，不是指令句。一般不抽取执行对象，可全部标 `0`。

## 9. 特殊情况处理

### 9.1 句子里没有任何固定人名

例如：

- `请两位同学讨论一下`

这种句子当前对象提取任务不输出固定名字，不写入对象提取数据，或者全部跳过。

### 9.2 超过 3 个名字

当前业务要求最多输出 3 个对象。标注时：

- 如果句子里明确有 4 个及以上执行者，优先按真实语义标注
- 但这类样本应尽量少收，避免和当前部署约束冲突

### 9.3 别名、昵称、简称

如果真实数据里出现别名：

- 先在 [people.json](D:\intentionRecogination\people.json) 的 `aliases` 中补充
- 标注时 `name` 列统一写规范名，不写别名

例如：

- 原句里如果出现某个昵称，对应 `name` 仍写标准名

## 10. 质量要求

标注时要重点保证：

- 同类句式前后一致
- 同一句里所有人名的判断互相一致
- 不要把“出现名字”误当成“执行对象”
- 讨论类和帮助类要严格区分

建议抽样复查以下高风险句式：

- `A和B讨论`
- `A帮B...`
- `A给B讲...`
- `A提醒B...`
- `A你来...`

## 11. 典型正反例

### 例 1

原句：

`张晓丹你和丽娃讨论一下这个问题`

标注：

```csv
text,name,label
张晓丹你和丽娃讨论一下这个问题,张晓丹,1
张晓丹你和丽娃讨论一下这个问题,丽娃,1
张晓丹你和丽娃讨论一下这个问题,崔展豪,0
```

### 例 2

原句：

`张晓丹同学你帮丽娃解决一下这个问题`

标注：

```csv
text,name,label
张晓丹同学你帮丽娃解决一下这个问题,张晓丹,1
张晓丹同学你帮丽娃解决一下这个问题,丽娃,0
张晓丹同学你帮丽娃解决一下这个问题,包梓群,0
```

### 例 3

原句：

`请崔展豪来回答，回答完后再请李昌龙补充`

如果你当前只标第一动作的直接执行者，可以写：

```csv
text,name,label
请崔展豪来回答，回答完后再请李昌龙补充,崔展豪,1
请崔展豪来回答，回答完后再请李昌龙补充,李昌龙,1
请崔展豪来回答，回答完后再请李昌龙补充,张晓丹,0
```

如果你后面要区分主动作和次动作，需要单独扩任务定义；当前版本先统一按“本句中被要求执行动作的人”处理。
